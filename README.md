# 接单报价计算器

一个零依赖的 Python 小工具，帮助做 PPT、修图、文案、翻译等自由职业的人估算报价与时间安排。

输入每单报价、总工时、成本和平台手续费，即可看到：

- 每单扣除直接成本与手续费后的收益。
- 包含沟通、制作与修改时间的实际时薪。
- 达到月收益目标至少需要多少单、多少小时。
- 当前可用时间最多能完成多少单，以及对应月收益。

## 运行

需要 Python 3.8 或更高版本，无需安装第三方库，也不需要 API 密钥。

下载本仓库，在所在目录打开终端后运行：

```bash
python quote_calculator.py --price 99 --hours 2 --cost 9
```

Windows 如果找不到 `python`，可以尝试 `py`；macOS / Linux 可以使用 `python3`。

这组输入表示每单收费 99 元，制作与沟通共 2 小时，直接成本 9 元。输出包括：

```text
每单收益：90.00 元
实际时薪：45.00 元/小时
月目标 3000.00 元：至少需要 34 单
所需工时：68.00 小时
按每月 60.00 小时，最多可完成 30 单
全部完成时的月收益：2700.00 元
```

有平台抽成时，例如按成交额收取 5%：

```bash
python quote_calculator.py --price 199 --hours 3 --cost 10 --fee-rate 5 --target 3000 --available-hours 60
```

查看所有参数：

```bash
python quote_calculator.py --help
```

## 参数

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `--price` | 每单报价，大于 0 | 必填 |
| `--hours` | 每单总工时，大于 0 | 必填 |
| `--cost` | 每单直接成本 | 0 |
| `--fee-rate` | 平台手续费百分比，范围为 0 到小于 100 | 0 |
| `--target` | 月收益目标 | 3000 |
| `--available-hours` | 每月可用工时 | 60 |

所有金额统一按人民币显示；不应混用不同币种。数值最多支持四位小数。

## 计算方法

```text
每单手续费 = 每单报价 × 手续费比例 ÷ 100
每单收益 = 每单报价 − 每单直接成本 − 每单手续费
实际时薪 = 每单收益 ÷ 每单总工时
目标订单数 = 月收益目标 ÷ 每单收益，向上取整
月订单容量 = 每月可用工时 ÷ 每单总工时，向下取整
```

每单收益小于或等于 0 时，会提示无法靠增加订单实现正收益目标；目标为 0 时需要 0 单。

计算中使用 `Decimal`，展示金额与工时保留两位小数，订单数根据未舍入的结果计算。平台逐单结算时可能采用不同的分币舍入规则。

这是基于输入假设的估算，不包含未填写的税费、固定开支、退款或获客时间，也不保证能接到相应数量的订单。
